1. Topic prioritisation
Tier 1
 Most important: Study thoroughly

These topics deserve the most preparation. Understand the working, formulas, advantages, limitations and numerical applications.
Topic	What to prepare
Linear Regression	Equation, cost function, coefficients, predictions
Logistic Regression	Sigmoid, probability, classification
Ridge, Lasso, Elastic Net	Regularisation, L1 vs L2
K-Means Clustering	Centroids, iterations, WSS, elbow method
PCA	Variance, eigenvectors, dimensionality reduction
Decision Trees	Entropy, Information Gain, Gini Index
Random Forest	Bagging, feature selection, voting
SVM	Hyperplane, margin, kernels
KNN	Distance calculations, choosing K
Naive Bayes	Bayes theorem, conditional probability
Model Evaluation	Confusion matrix, precision, recall, F1, accuracy
Time Series	AR, MA, ARMA, ARIMA
Association Rules	Support, confidence, lift, Apriori

DBSCAN	Epsilon, MinPts, core/border/noise
Polynomial Regression	Polynomial equation, overfitting
Cross Validation	K-Fold, train/test validation
Grid Search & Random Search	Hyperparameter optimisation
Gradient Boosting	Sequential error correction
Model Stacking	Combining multiple models
Exponential Smoothing	Forecasting calculations
Holt's Method	Level and trend
Holt-Winters	Level, trend, seasonality
Recommendation Systems	Collaborative filtering, factorisation
Anomaly Detection	Isolation Forest, anomaly types
